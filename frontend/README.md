# CashTrace Frontend

Minimal Next.js App Router app (TypeScript and Tailwind CSS). The dashboard and API integrations are not implemented yet.

This project uses Next.js 16 with Tailwind CSS v4. Styles are loaded through the Next.js/Turbopack pipeline, so there is no `postcss.config.mjs`.

## Setup

```powershell
cd frontend
npm install
```

## Start

```powershell
npm run dev
```

The app is available at [http://localhost:3000](http://localhost:3000).

## Production build

```powershell
npm run build
npm start
```
